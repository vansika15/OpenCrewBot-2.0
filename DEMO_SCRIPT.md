# 5–10 Minute Demonstration Script — OpenCrewBot 2.0

This script provides an exact, step-by-step walkthrough for recording the 5–10 minute demonstration of OpenCrewBot 2.0.

---

## Video Outline

| Time | Section | Screen & Action | Key Talking Points |
| :--- | :--- | :--- | :--- |
| **0:00 – 1:00** | **Introduction & Architecture** | Open browser to `http://localhost:3000`. Show the clean workforce dashboard. Point out the 8 agents in the sidebar and 4 collaboration rooms. | "Welcome to OpenCrewBot 2.0. We extended the open-source MIT OpenCrewBot into an autonomous enterprise AI workforce operating system." |
| **1:00 – 2:30** | **Demonstration 1: Chief of Staff & Market Intelligence** | Click into the **Executive Suite** room. Type: *"Chief of Staff, conduct comprehensive market intelligence on MeetUniversity competitors."* Or open the **Task Dashboard**. | "Notice how the Chief of Staff decomposes the goal into a DAG of 3 tasks: Competitive Landscape, Differentiation Analysis, and Executive Consolidation. Independent tasks run in parallel across Radar, Scout, and Atlas." |
| **2:30 – 3:30** | **Demonstration 2: Marketing Campaign & Agent Factory** | Click the `+` icon in the sidebar and select **Create Agent with AI**. Type: *"Create a Class 11 Student Engagement Strategist for Aspirations."* Show the synthesized agent. | "Notice that without changing a single line of source code, the new agent is deployed, assigned tools and memory, and immediately available." |
| **3:30 – 4:30** | **Demonstration 3: Business & Sales Funnel Analysis** | Open the **Reusable Skills** modal. Select **Data Analysis** and click **Test Skill**. Show the tabular sales pipeline calculations. | "Here is real data analysis on a 12,500 lead dataset. It calculates conversion drop-offs, identifies the 56.9% bottleneck at the diagnostic stage, and models a +INR 42.5 Lakh revenue upside." |
| **4:40 – 5:40** | **Demonstration 4: Development Team & GitHub Integration** | Show the **Engineering Review** room. Agent Forge inspects the GitHub repository, audits code quality, and stages a PR draft. | "The Development Team inspected the actual codebase, flagged the Next.js dependency advisory, and staged a pull request proposal." |
| **5:40 – 6:40** | **Demonstration 5: Scheduled AI Workflows** | Open the **Scheduled Workflows** modal. Point out the *Competitor Intelligence Sentinel*. Click **Trigger Now**. Then click **Pause** and **Resume**. | "Our automation engine runs recurring routines in the background. Here you see the execution history and pause/resume controls." |
| **6:40 – 7:40** | **Demonstration 6: Memory Persistence & Editing** | Open the **Enterprise Memory** modal. Show `MEMORY.md`. Edit a preference directly (e.g., change *"brief bullets"* to *"narrative prose"*). Save and demonstrate that the agent respects the correction. | "Our memory architecture is stored in human-readable Markdown with provenance. When edited, the agent immediately adapts." |
| **7:40 – 8:40** | **Demonstration 7: Human Intervention & Action Rejection** | Open the **Approval Centre**. An agent attempts an external email dispatch. Show the **Action Preview**. Click **Reject Action**. | "Under our 3-Tier Security model, sensitive operations request human approval. We reject this action, and the audit log proves it was never dispatched." |
| **8:40 – 9:00** | **Conclusion** | Show the **Test Report** (17/17 passed) and GitHub repository. | "OpenCrewBot 2.0 delivers a complete, verified, enterprise-ready AI workforce. Thank you." |
